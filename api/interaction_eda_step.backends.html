interaction_eda_step.backends.base module#

The interface between the Interaction EDA step and the codes that do the EDA.

A backend runs a batch of EDA calculations, one per set of fragments, in its own environment through seamm_exec. The step knows only this interface:

  • what the backend can do (Backend.scheme, Backend.device, Backend.max_fragments, Backend.options()), so the GUI can offer only valid choices;

  • Backend.files() – the input files for a batch;

  • Backend.ini and Backend.command() – how seamm_exec runs it;

  • Backend.read_results() – the native terms of each calculation, kJ/mol.

Backends planned: gpu4pyscf (ALMO-EDA2 on a GPU), psi4_almo (ALMO-EDA2 on CPUs) and psi4_sapt (SAPT0/F-SAPT, dimers only).
